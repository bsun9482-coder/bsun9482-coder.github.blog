# 个人技术博客方案：Grill / Discovery Notes
Date: 2026-09-20 · Goal: 明确博客目标、内容工作流、功能范围与发布方式，并产出可执行的推荐方案。

## Summary / key decisions

- 已有技术底座：Vite + React + TypeScript + Tailwind CSS v4 + shadcn/ui。
- 已知内容方向：Python 与 AI 学习笔记。
- 视觉与体验参考：`https://www.sansphase.com/`，目标是做一个类似风格的博客。
- 参考站核心特征：沉浸式星空/宇宙首页、深色玻璃面板、细线边框、蓝色高光、固定顶部导航。
- 参考站博客结构：文章搜索与分类、列表/网格切换、作者信息、音乐播放器、标签、天气/时间辅助卡片。
- 参考站文章结构：作者侧栏、音乐播放器、文章目录、正文、标签与分享。
- 首版范围：首页（样式待定）、导航、文章列表、搜索/分类、文章详情、文章目录。
- 首版不做：音乐播放器、天气、登录后台及其他扩展功能。
- 内容工作流：文章使用仓库内 MDX，通过 Git 提交与网站构建发布；不需要数据库或管理后台。
- 产品定位：纯知识库；弱化个人介绍，优先展示搜索、分类和文章内容。
- 首页内容组织：传统博客时间流，文章按发布时间倒序展示；搜索和分类用于辅助查找。
- 核心读者：Python/AI 初学者；文章需要包含背景说明、可复现步骤、示例和常见错误。
- 首页视觉方案：暂未决定，延期到设计阶段，不阻塞内容结构与核心功能开发。
- 部署与 SEO：首版只完成本地版本；部署平台、自定义域名、静态预渲染和搜索引擎收录均延后到部署阶段决定。
